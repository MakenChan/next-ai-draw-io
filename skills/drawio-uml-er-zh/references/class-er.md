# 类图
- 每个类清晰分为类名、属性、方法三段；属性和方法逐行左对齐。
- 不凭空加入 BaseEntity。
- 关系只使用 UML 标准类型：继承、实现、依赖、关联、聚合、组合。
- 关系线吸附类框边界，避免悬空线头。

# Crow's Foot ERD
- 实体采用表格：表名、字段名、类型、约束；至少标出 PK、FK，必要时 UK。
- 字段名与项目总结保持一致，不得发明字段。
- 关系直接连接实体表，不使用 Chen 菱形。
- 每条关系两端必须有 Crow's Foot 基数标记：ERmandOne=1..1，ERzeroToOne=0..1，ERoneToMany=1..N，ERzeroToMany=0..N。
- 基数由 FK 与业务约束共同推导；无法证明最小基数时采用保守的 0..N。
- 多对多应展开为关联实体，除非总结明确只描述概念级关系。
- 正交走线，关系线不穿过实体表。
